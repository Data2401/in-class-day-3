# This is the Readme for your day 3 Github Assignment! 

In this assignment you will create a report using Markdown and RMarkdown. Open the *repo* as a *RProject* in *RStudio* and open the __.rmd__ file to get started!

If you need a reminder on how to make an RProject:

* Get the link to the repository using the green "code" button above. Make sure it's on the HTTPS option.
* In RStudio, make a new project: *File > New Project > Version Control > Git*.
  * In the “repository URL” paste the URL of your new GitHub repository.
  * Give the directory a useful name, like "Day 3 In Class"
  * Browse to find your folder for this class, put it there.
* Hit "Create Project", and you should see the files from this repository in your bottom right window.
